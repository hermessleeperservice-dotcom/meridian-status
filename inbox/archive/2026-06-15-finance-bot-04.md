## Important — split into two non-blocking commands

Do **not** use a single script with a blocking `input()` call. As an autonomous agent you cannot sit on an interactive prompt. Split the flow so each step is a separate, self-contained command.

### Command 1 — generate the URL and exit

Write a small helper (e.g. `oauth_step1.py`) in the financebot directory:

```python
from google_auth_oauthlib.flow import InstalledAppFlow
import pickle

SCOPES = ['https://www.googleapis.com/auth/youtube.upload']
flow = InstalledAppFlow.from_client_secrets_file('client_secret.json', SCOPES)
auth_url, _ = flow.authorization_url(prompt='consent', access_type='offline')

# Persist the flow state so step 2 can resume it
with open('oauth_flow.pickle', 'wb') as f:
    pickle.dump(flow, f)

print('AUTH_URL:', auth_url)
```

Run it, capture the printed `AUTH_URL`, and send Tomasz this Telegram:
"Finance Bot OAuth — open this URL, sign in with wealthsecrets1970@gmail.com, then paste the code back to me here:
<AUTH_URL>"

Then stop and wait for the code. Do not poll or retry.

### Command 2 — exchange the code (run when Tomasz replies)

When Tomasz pastes the code into Telegram, run `oauth_step2.py <code>`:

```python
import sys, pickle

with open('oauth_flow.pickle', 'rb') as f:
    flow = pickle.load(f)

flow.fetch_token(code=sys.argv[1].strip())
creds = flow.credentials

with open('token.pickle', 'wb') as f:
    pickle.dump(creds, f)

print('TOKEN_WRITTEN')
```

If `fetch_token` raises `redirect_uri_mismatch` or `invalid_grant`, **stop** and report it verbatim in your loop update — do not retry with variations. That error means the OAuth client does not allow the out-of-band redirect, and we will need to wait for Tomasz to be home for Option A or adjust the client config. It is not something to brute-force.
